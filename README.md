# 图纸浏览器 - 使用说明

一个专为工厂车间设计的安卓图纸浏览APP，支持小米平板等安卓设备。

## 功能特性

- **文件夹浏览**：按文件夹层级浏览图纸，支持多层子文件夹
- **大图查看**：双指缩放、拖动查看、左右滑动切换图片
- **图片旋转**：一键旋转90度，适合横版图纸
- **搜索功能**：按文件名搜索图纸，快速定位
- **收藏夹**：常用图纸加入收藏，一键直达
- **最近浏览**：自动记录最近查看的图纸
- **全部图纸**：递归显示所有图纸图片
- **平板适配**：自动适配平板屏幕，横屏竖屏都好用
- **纯本地**：不需要联网，所有数据都在本地

## 图纸存放位置

APP 默认读取的目录是：
```
内部存储/图纸/
```

你可以在这个文件夹里建任意多层子文件夹，比如：
```
图纸/
├── 甲方A公司/
│   ├── 2024-08项目/
│   │   ├── 001-主视图.jpg
│   │   ├── 002-俯视图.jpg
│   │   └── 003-侧视图.jpg
│   └── 2024-09项目/
├── 甲方B公司/
│   └── ...
└── 通用图纸/
    └── ...
```

支持的图片格式：JPG、JPEG、PNG、BMP、GIF、WEBP

## 如何编译安装

### 方法一：用 Android Studio 编译（推荐）

1. 下载安装 [Android Studio](https://developer.android.com/studio)
2. 打开 Android Studio，选择 "Open an Existing Project"
3. 选择本项目文件夹（DrawingViewer）
4. 等待 Gradle 同步完成（第一次需要下载依赖，时间较长）
5. 用 USB 线连接平板，打开平板的 USB 调试模式
   - 设置 → 我的设备 → 全部参数与信息 → 连续点击 MIUI 版本 开启开发者模式
   - 设置 → 更多设置 → 开发者选项 → 开启 USB 调试
6. 点击 Android Studio 顶部的 ▶ Run 按钮
7. 选择你的平板设备，APP 会自动安装并启动

### 方法二：生成 APK 文件手动安装

1. 在 Android Studio 中打开项目
2. 菜单选择 Build → Build Bundle(s) / APK(s) → Build APK(s)
3. 编译完成后点击 "locate" 找到 APK 文件
4. 把 APK 文件传到平板上
5. 在平板的文件管理器里点击 APK 安装
   - 第一次安装需要允许"未知来源"安装

## 首次使用

1. 安装后首次打开 APP，会请求存储权限
2. 点击"授予权限"，允许访问所有文件
3. 把图纸放到平板的 `内部存储/图纸/` 文件夹里
4. 打开 APP 就能看到你的图纸文件夹了

## 操作说明

### 浏览图纸
- 点击文件夹进入
- 点击图片打开大图查看
- 左上角菜单按钮 ☰ 打开侧边栏

### 大图查看
- **双指缩放**：捏合放大缩小
- **拖动**：单指拖动查看细节
- **左右滑动**：切换上一张/下一张
- **单击图片**：显示/隐藏顶部工具栏
- **收藏按钮 ☆**：添加/取消收藏
- **旋转按钮 ↻**：图片顺时针旋转90度

### 搜索
- 点击右上角搜索图标 🔍
- 输入图纸名称关键字，自动搜索
- 支持模糊匹配

### 侧边栏
- **首页**：默认图纸文件夹
- **收藏**：你收藏的图纸
- **最近浏览**：最近看过的图纸（最多50张）
- **全部图纸**：递归显示所有图纸图片

## 常见问题

### Q: 打开APP看不到图纸？
A: 检查以下几点：
1. 是否授予了存储权限
2. 图纸是否放在了 `内部存储/图纸/` 文件夹里
3. 图片格式是否是 JPG/PNG 等支持的格式

### Q: 图片加载很慢？
A: 第一次浏览会生成缩略图缓存，之后就快了。几千张图都没问题。

### Q: 横屏使用可以吗？
A: 完全可以，APP 自动适配横竖屏，横屏看大图更爽。

### Q: 收藏的图纸存在哪里？
A: 收藏记录保存在 APP 的本地数据里，不影响原图文件。删除 APP 收藏会丢失。
